
# Radiacode Analyzer

A Python project for reading, analyzing, and transforming CSV data exported from a Radiacode radiation detector.

## Goals

* Read and inspect CSV files
* Understand the structure of the exported data
* Calculate useful statistics
* Clean and transform data
* Export processed data to CSV
* Eventually visualize measurements with a GUI
* Explore a local web interface and embedded hardware integration

## Development

This project is written in Python and developed on Linux using Neovim.

## Status

Initial setup and CSV format investigation.
